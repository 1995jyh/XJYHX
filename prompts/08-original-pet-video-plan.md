# 우리 캐릭터 오리지널 영상 제작 계획 (2026-11-27)

## 방향 전환
- 지금까지 모은 남의 영상 = **올리는 용도가 아니라 "뭐가 터지는지" 배우는 레퍼런스**
- 실제 업로드 = **우리 캐릭터(햄스터 3형제 등)로 AI 영상 생성** → 저작권 문제 없음, 캐릭터 팬층 쌓임
- 레퍼런스 영상 자체를 AI 학습 데이터로 쓰거나 장면을 베끼지는 않음 → **포맷·구성·타이밍만 참고**

## 레퍼런스 분석 (동물 영상 53개, 조회수 기준)

### 1. 길이: 짧을수록 터짐
- 1,000만+ 영상 12개 중 9개가 **15초 이하**, 대부분 6~12초
- → 우리 영상은 **6~12초**가 기본

### 2. 터지는 포맷 5가지
| 포맷 | 대표 레퍼런스 (조회수) | 구조 |
|---|---|---|
| **A. 상황 자막 + 동물 표정 리액션** | 데이트 상대 마음에 안 드는 강아지 (6,320만), 면발 걸친 채 째려보는 강아지 (2,680만), 목줄 떨어뜨렸을 때 반응 (1,180만) | 상단 한 줄 자막(POV/상황) → 동물 클로즈업 표정 하나로 끝 |
| **B. 이상한 동물 × 평범한 일상** | 자전거 타는 카피바라 (1,680만), 물로 다이빙하는 카피바라 (3,580만), 목욕하는 고슴도치 (1,000만) | 사람이 하는 일상 행동을 동물이 태연하게 함 |
| **C. 시간 경과·성장** | 곧 안 들어갈 아기 코기 (2,430만), 얼굴 하얘지는 골댕이 | 같은 장소에서 "그때 vs 지금" |
| **D. 밈 음악 + 동작 싱크** | 브리저튼 춤 강아지 (1,960만), 이 노래 금지시킨 이유 (1,450만) | 유행 음악 + 동물 동작 박자 맞춤 |
| **E. 사람처럼 말하기·대꾸** | 말대꾸 허스키 (220만), 웃는 앵무새 (560만), 말하는 프렌치불독 (510만) | 동물 소리를 대사처럼 자막 처리 |

### 3. 공통 요소
- 첫 1초 안에 동물 얼굴 클로즈업
- 상단에 짧은 영어/한국어 한 줄 자막 (상황 설명)
- 결말은 "표정 하나" 또는 "어이없는 행동 하나" — 설명 없이 끝
- 배경은 집·산책길 등 평범한 일상 → 실사 느낌이 중요

## 제작 파이프라인 (제안)
1. **레퍼런스 수집**: 지금 자동화 유지하되 업로드용 전송은 줄이고, 주 1회 "포맷 분석 리포트"로 정리
2. **기획 (매일 자동)**: 위 5개 포맷 × 우리 캐릭터로 오늘 만들 영상 3개 기획
   - 장면 설명, 첫 프레임 이미지 프롬프트, 영상 프롬프트(6~10초), 상단 자막, X 게시글
3. **생성**: 캐릭터 기준 이미지 → 이미지→영상(image-to-video) 생성
   - 수동: Sora / Veo(Gemini) / Kling / Hailuo 앱에 프롬프트 붙여넣기
   - 자동: 영상 AI API 키 연결 시 스크립트가 생성까지 처리 (유료)
4. **편집**: 자막·음악은 CapCut 등에서, 또는 ffmpeg로 자막 자동 삽입 가능
5. **업로드 + 성과 기록**: 어떤 포맷이 잘 됐는지 다시 1번에 반영
