# 무료 자동화 경로 조사 (2026-11-24)

> 웹 검색으로 조사한 결과. 대부분 2026년 하반기 2차 블로그 자료이고, 이 환경은 네트워크가 막혀 있어서 **직접 접속 테스트는 못 했음**. 아래 내용은 허용 도메인을 추가한 뒤 실제로 돌려서 검증해야 함.

## 현재 환경
- 외부 사이트 대부분 차단 (x.com, tiktok, instagram, youtube, giphy, reddit 등). 패키지 저장소(pypi)만 열려 있음.
- 웹 검색은 가능. 단, 제목·링크만 나오고 좋아요·조회수·영상 길이는 확인 불가.

## 1. X (트위터)

| 방법 | 비용 | 쓸모 | 비고 |
|---|---|---|---|
| 공식 X API | 유료 | 검색 + 수치 | 2026-02부터 무료 티어 없음, 종량제 (게시물 읽기 1건당 약 $0.005) |
| xcancel / nitter.net | — | — | xcancel 정지(451), nitter.net 종료 |
| 커뮤니티 nitter 인스턴스 (nitter.netbub.com 등) | 무료 | 검색 가능할 수도 | 수시로 죽음, 불안정 |
| **api.fxtwitter.com** | 무료 | **링크 → 본문·수치 확인** | 키·로그인 불필요. 단 검색은 안 됨, URL을 알아야 함 |
| **trends24.in** (한국 실트) | 무료 | **지금 뜨는 키워드 파악** | 매시간 국가별 트렌드. 게시물 자체는 안 나옴 |

**추천 우회 방식 (반자동):**
1. trends24 한국 페이지로 지금 뜨는 키워드 확인 + 웹 검색으로 관련 X 게시물 링크 찾기
2. 또는 네가 폰에서 `min_faves:500 lang:ko` 검색해서 링크 몇 개 던져주기
3. 내가 fxtwitter API로 각 링크의 본문·좋아요·조회수를 직접 확인한 뒤 인용글 초안 작성
→ 수치는 실제 확인값이라 "지어내기 금지" 규칙을 지킬 수 있음

## 2. TikTok — 조회수순 / 최신순 정렬

- **앱 검색 필터:** 정렬은 "관련성 / 좋아요 많은 순"만 있음. **조회수순 정렬은 없음.** "게시 날짜" 필터(이번 주, 최근 3개월 등)로 기간을 좁힐 수는 있음.
- **웹(tiktok.com) 검색:** 정렬 자체가 없음 (크롬 확장 프로그램으로만 가능).
- **TikTok Creative Center (ads.tiktok.com) 트렌드:** 무료이고, 지역·기간별로 인기 영상을 핫·좋아요·댓글·공유 순으로 정렬할 수 있음. 로그인 없이 일부는 보이지만 전체를 보려면 로그인이 필요하다는 자료도 있음.
- **수치 확인:** yt-dlp가 공개 영상 URL에서 조회수·길이를 뽑을 수 있음 (`--impersonate` 필요할 수 있음).

**추천:** Creative Center로 후보 찾기 → yt-dlp로 실제 길이·조회수 확인 → 조건(동물 30초 미만, 음식 15~55초)에 맞는 것만 남기기. 최신순 대신 "최근 7일 + 좋아요순"이 현실적임.

## 3. Instagram

- 무료 + 로그인 없이 릴스 **조회수를 안정적으로 가져오는 방법은 확인 못 함**.
- instaloader 테스트에서 릴스 40개 포함 72개 전부 view_count가 비어 있었다는 보고가 있음. yt-dlp도 대부분 로그인 쿠키가 필요함.
- 계정 쿠키를 쓰면 계정 정지 위험이 있음.

**추천:** 인스타는 자동 수집에서 빼거나, 네가 링크를 주면 내용 정리만 하기. 조회수는 "확인 불가"로 표시.

## 4. YouTube Shorts (제일 쉬움)

- YouTube Data API v3 무료 (Google Cloud 키 필요, 하루 쿼터 있음).
- `order=viewCount`(조회수순) 또는 `order=date`(최신순), `publishedAfter`(기간), `videoDuration=short` 조합 가능 → 조회수순이랑 최신순 둘 다 됨.
- 영상 길이·조회수는 videos.list나 yt-dlp로 정확히 확인 가능.
- 쿼터 계산 방식은 자료마다 다르니(검색 1회 = 1단위 vs 100단위) 실제로 써보고 확인해야 함.

## 실제 접속 테스트 결과 (2026-11-24, XJYHX 환경)

X는 자동화 대상에서 제외하기로 함.

| 항목 | 결과 | 비고 |
|---|---|---|
| 유튜브 검색 → 조회수순 + 길이 | ✅ 됨 | yt-dlp `--flat-playlist`로 조회수·길이·URL 확인 (예: 18초 / 4.5억 회 쇼츠) |
| 유튜브 "이번 주" 필터 | ⚠️ 애매 | 결과가 쇼츠 위주가 아니고 날짜 확인 불가. 개별 영상 페이지는 "봇 확인"에 걸림 |
| 틱톡 태그·검색 페이지 직접 크롤링 | ❌ 안 됨 | 페이지는 뜨지만 영상 목록 API가 빈 응답("Something went wrong"). 클라우드 IP 봇 차단으로 보임 |
| 틱톡 Creative Center | ❌ 안 됨 | 로그인 요구 / 403 |
| **틱톡: 웹 검색으로 영상 URL 찾기 → yt-dlp로 확인** | ✅ 됨 | 예: @agirlandadoodle 29초 · 조회 6,320만 · 좋아요 1,110만 / @scottyhubs 13초 · 조회 510만 |
| KnowYourMeme | ✅ 됨 | 밈 페이지 목록 수집 가능 |
| Giphy / Klipy API | 🔑 키 필요 | 접속은 됨(401/204). 무료 키 발급하면 사용 가능 |

### 확정된 틱톡 수집 방식
1. 웹 검색(tiktok.com 한정)으로 키워드별 영상 URL 후보 수집
2. yt-dlp `--impersonate chrome`으로 각 영상의 조회수·좋아요·길이·업로드 날짜를 직접 확인
3. 조건(동물 1~29초, 음식 15~55초) 필터링 후 조회수순 정렬. 최신순이 필요하면 업로드 날짜로 정렬
