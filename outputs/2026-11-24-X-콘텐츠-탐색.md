# X에 추가로 올릴 만한 콘텐츠 탐색 (2026-11-24)

> 실제로 접속해서 데이터가 뽑히는지 확인한 결과 기준.

## ✅ 바로 자동화 가능 (이미 스크립트에 넣음)

| 콘텐츠 | 소스 | X 글 예시 | 명령 |
|---|---|---|---|
| **음원 차트 변동** | 멜론 TOP100, 지니 TOP200 | "멜론 TOP10에 리센느만 4곡 실화임?", 급상승·신규 진입 | `chart` (직전 스냅샷 대비 변동 자동 계산) |
| **아이돌 소식·비하인드** | 네이트판 엔터톡, 디시 실베, 인스티즈 이슈 (아이돌 키워드 필터) | 인터뷰 비하인드, 예능·다큐 일화, 투어 소식 | `list --mode idol` |
| **해외에서 화제된 K팝 소식** | 숨피 (영문 K팝 뉴스) | "해외 매체에도 바로 뜬 ○○ 소식" | `list --mode idol` (숨피 포함) |
| 연예 화제글 | 판·디시·인티 | (기존) | `list` |
| 꿀팁 | 클리앙 팁과강좌 + 키워드 | (기존) | `list --mode tips` |
| 해외 틱톡 음식·트렌드 영상 | 웹검색 + yt-dlp | (기존, 수동 실행) | 문서 4 |

## ⚠️ 가능하지만 추가 작업 필요

| 콘텐츠 | 상태 | 메모 |
|---|---|---|
| 써클차트 주간 앨범·디지털 순위 | 페이지는 열리는데 순위 데이터가 JS로 로딩됨 | 내부 API 찾으면 가능. 주 1회 "이번 주 앨범 판매 TOP10" 글감 |
| 신곡 MV 조회수 기록 | 소속사 유튜브 채널 목록에서 최신 MV 조회수가 대부분 NA | 영상 검색 결과 경유로 우회 가능성 있음. "공개 하루 만에 ○만 회" 글감 |
| 아이돌 브랜드평판 월간 순위 | 한국기업평판연구소(rep-k) 접속 불가(502) | 매달 기사로 나오니 웹 검색으로 월 1회 정리는 가능 |
| 음방 1위·컴백 일정 | 공식 소스 미확인 | 웹 검색 기반이면 정확도 검수 필요 |

- 꿀팁: 하루 2회 (기존)
